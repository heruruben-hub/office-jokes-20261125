This entry is one office joke, told in a single line.

The joke lands because the office never fixes the problem.

It only schedules a meeting about the problem.

That meeting even gets a cheerful title, as if a title were a solution.

The punchline is the calendar invite itself, arriving like a rescue that rescues nothing.

Run `node main.ts` and the joke is written to `/output/entry.txt`.
